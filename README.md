# 🧠 AI Resume Builder

An AI-powered resume builder built using **Flask**, **TailwindCSS**, and **Flowbite** — developed by Subhash Govindharaj and team at GUVI 💚

---

## 📦 Tech Stack

- ⚙️ Backend: Flask (Python)
- 🎨 UI: HTML, Tailwind CSS, Flowbite
- 🧠 AI (Coming Soon): OpenAI / HuggingFace Integration
- 🌐 Deployment Ready: GitHub Pages or Flask Host

---

## 🚀 Features

- User-friendly resume form
- Beautiful responsive layout
- Dark mode ready via Flowbite
- AI integration coming soon for auto-suggestions

---

## 🛠️ Setup Instructions

```bash
# Clone this repo
git clone https://github.com/SubhashGovindharaj/Resume_Builder.git
cd Resume_Builder

# (Optional) Create a virtual environment
python -m venv venv
venv\Scripts\activate  # Windows

# Install dependencies
pip install -r requirements.txt

# Start the Flask server
python app.py
